# Linux Administration Scripts

## Objectif

Mettre en pratique les bases de l'administration Linux en développant plusieurs scripts Bash utiles pour un administrateur système.

---

## Compétences

- [x] Navigation dans le terminal
- [x] Gestion des fichiers
- [x] Lecture des informations système
- [x] Utilisation de commandes Unix
- [x] Parsing de sorties avec awk
- [x] Gestion des arguments Bash
- [x] Validation d'entrées utilisateur
- [x] Codes de sortie
- [x] Documentation de scripts
- [x] Permissions Linux
- [x] Utilisateurs et groupes
- [x] Processus
- [x] Journalisation (logs)
